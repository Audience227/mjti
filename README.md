# mjti · 测测你是MJ宇宙中的哪一位

（品牌名统一小写 `mjti`）

24 题 × 4 选 1 的趣味人格测试 H5，纯前端零依赖，结果带参分享。**图片只在最终结果页出现**，首页与答题过程不展示任何结果图（保留悬念感，也是这类爆款测试的通用做法）。

## 本地预览

直接双击 `index.html`，或：

```
cd mjti
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

## 部署到 GitHub Pages（免费上线）

1. 在 GitHub 新建仓库（Public），把 `index.html`、`data.js`、`main.js`、`img/` 整个传上去
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/ (root)` → Save
3. 等 1-2 分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`
4. 手机浏览器打开验证一遍即可分享

## 目录结构

```
mjti/
├── index.html   # 页面结构+样式（手机端优先）
├── data.js      # 全部题目、权重、结果文案 —— 改内容只动这个文件
├── main.js      # 计分引擎：累加权重取最高分；奇异博士按严肃/搞笑分值细分双结果
└── img/         # 10 张结果图（用户素材 7 张 + AI 补 3 张，均无水印）；rocket.png 为备用图，当前页面未使用
```

## 二次修改指南

- **改题目/选项/文案**：只改 `data.js`，引擎不用动
- **加结果**：在 `RESULTS` 里加条目，`ROLES` 加对应角色代码，题目权重里引用
- **改分享链接**：结果链接格式 `index.html#r=<key>`，打开自动展示该结果
- 校验脚本思路：node 模拟 N 次随机作答，确认每个结果可达且分布合理

## 已知限制与合规提示

- 漫威角色名称与形象版权属迪士尼，本测试为娱乐用途的自制梗图玩法；**可免费分享，不建议上架售卖**（卖 IP 内容有侵权风险）
- 纯前端无统计，`已测试人数` 若需要需另接轻量后端
- 结果图如需「长按保存」海报，可后续加 Canvas 合成（html2canvas 或原生绘制）
